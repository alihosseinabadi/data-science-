# data-science-school 21
# Data Science Комплексный учебный проект - School 21

## 🎯 Цель проекта

**Основная цель:** Систематическое освоение полного цикла Data Science — от базовых навыков программирования до построения production-ready ML моделей. Проект разработан для формирования глубокого понимания каждого этапа работы с данными в реальных условиях.

**Ключевые задачи:**
- Поэтапное освоение всех необходимых навыков data scientist
- Практическое применение теоретических знаний на реальных данных
- Формирование портфолио с полными проектами
- Подготовка к решению сложных задач машинного обучения

## 📚 Полная программа обучения

### Этап 1: Фундаментальные основы
**Базовые операции и программирование**
- Основы Python: типы данных, структуры, контроль выполнения
- Работа с файлами: чтение/запись, форматы (CSV, JSON, Excel)
- Функции и модульность: создание переиспользуемого кода
- ООП в контексте Data Science: классы для обработки данных

**Оптимизация и производительность**
- Анализ временной сложности алгоритмов (Big O notation)
- Профилирование кода: выявление узких мест
- Векторизация операций с NumPy
- Эффективное использование памяти

**Виртуальные окружения и инфраструктура**
- Создание изолированных окружений (venv, conda)
- Управление зависимостями (requirements.txt, pipenv)
- Основы Docker для воспроизводимости
- Настройка среды разработки (Jupyter, VS Code)

### Этап 2: Работа с данными
**SQL для Data Science**
- Сложные запросы: оконные функции, CTE, подзапросы
- Оптимизация запросов: индексы, планы выполнения
- Проектирование схем баз данных
- Работа с временными рядами в SQL

**Pandas - продвинутые техники**
- MultiIndex и иерархические данные
- Векторизированные операции и apply-функции
- Работа с большими датасетами (chunking, dask)
- Кастомные трансформеры и пайплайны

**Data Analyst - полный цикл анализа**
- Постановка бизнес-задач в терминах данных
- Разведочный анализ данных (EDA) с автоматизацией
- Статистический анализ: проверка гипотез, корреляции
- Создание аналитических отчетов и дашбордов

**Data Scraping и сбор данных**
- Парсинг веб-страниц: BeautifulSoup, Scrapy
- Работа с API: REST, GraphQL, аутентификация
- Обход анти-scraping систем
- Хранение и организация собранных данных

### Этап 3: Машинное обучение
**ML Basics - фундаментальные алгоритмы**
- Линейная и логистическая регрессия
- Деревья решений и случайные леса
- Кластеризация: k-means, DBSCAN, иерархическая
- Метрики качества: точность, полнота, F1, ROC-AUC

**Подготовка данных для ML**
- Обработка пропущенных значений
- Кодирование категориальных признаков
- Масштабирование и нормализация
- Работа с дисбалансом классов

**ML Advance - продвинутые техники**
- Ансамбли моделей: бэггинг, бустинг, стэкинг
- Понижение размерности: PCA, t-SNE, UMAP
- Подбор гиперпараметров: GridSearch, RandomSearch, Optuna
- Интерпретация моделей: SHAP, LIME, feature importance

### Этап 4: Production и тестирование
**Тестирование Data Science кода**
- Unit тесты для функций обработки данных
- Интеграционные тесты для ML пайплайнов
- Тестирование воспроизводимости результатов
- Pytest: фикстуры, параметризация, покрытие

**Проектная структура и best practices**
- Организация проекта по шаблону Cookiecutter
- Верификация данных (Great Expectations)
- Логирование и мониторинг
- Документирование кода и процессов
